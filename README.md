>

> 
> **Prerequisites**: Basic computer literacy, motivation to learn

- [ ] Complete NetPractice levels 0-2
- [ ] Focus on basic IP assignment and connectivity

## 🛠️ Essential Tools & Resources

### Quick Reference Formulas
```
Network Size = 2^(32-CIDR) addresses
Host Count = Network Size - 2 (network + broadcast)
Subnet Increment = 256 - Subnet Mask Octet
```

### Debugging Checklist
1. **IP Configuration**: Correct network assignment?
2. **Subnet Masks**: Consistent across network?
3. **Default Gateway**: Points to router interface?
4. **Routing Table**: Routes to all destinations?
5. **Interface Status**: All interfaces active?

## 💡 Pro Tips for Success

### ⚡ Efficiency Hacks
- **Always draw first**: Visualize before configuring
- **Break it down**: Complex → Simple components
- **Use hints wisely**: Only when truly stuck
- **Pattern recognition**: Similar exercises have similar solutions

### 🧠 Learning Strategy
- **Understand, don't memorize**: Focus on "why" not "what"
- **Practice active recall**: Explain concepts aloud
- **Learn from mistakes**: Each error teaches something valuable
- **Build incrementally**: Master basics before advancing

### ⚠️ Common Pitfalls to Avoid
- Overlapping subnets
- Wrong gateway assignments
- Inconsistent subnet masks
- Missing routes in routing tables
- Inactive interfaces
